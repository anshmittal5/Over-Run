# Over-Run

A 2D top-down survival shooter made in unity.

Survive as long as you can, defeat enemies, and keep moving.

## About the Game

Over-Run is a top-down 2d survival shooter built as my first self-made Unity game

The goal is simple: survive for as long as possible while enemies continuously chase and attack the player. Use movement, 
dashing, automatic gunfire, and a shockwave ability to stay alive and defeat enemies 

## Features

- Top-down survival shooter
- WASD / Arrow Key movement
- Dash Ability
- Automatic Handgun targeting the nearest enemy
- Manual shockwave ability
- Enemy chasing and attacking AI
- Health, score, and survival timer systems
- Cooldown UI for abilities
- Pause and restart system

 ## Controls

| Action | Key |
|---|---|
| Move | WASD / Arrow keys |
| Dash | Space Bar |
| Shockwave | C |
| Pause / Resume | Esc |

## Built With

- Unity 2022 LTS
- C#
- Unity input system
- TextMesh Pro
